# Uptime Monitor

A full-stack website monitoring platform that tracks uptime, response times, incidents, and service health.

## Live Demo

Frontend:
https://uptime-monitor-alpha-bay.vercel.app

Backend Health:
https://uptime-monitor-2lby.onrender.com/actuator/health

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Java 17
- Spring Boot
- Spring Data JPA
- Flyway
- PostgreSQL

### DevOps
- Docker
- Docker Compose
- GitHub Actions
- Render
- Vercel
